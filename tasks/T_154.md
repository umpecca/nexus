# T_154: Folder Browser and File Management

## Status

Done

## Summary

Open a local folder in a sidebar, browse its directory tree, and open Markdown/text documents
through the existing unsaved-change flow. Manage files and folders without leaving Nexus.

## Acceptance Criteria

1. File / Open Folder uses a native folder picker and displays a lazy directory tree in every editor mode.
2. Clicking Markdown, MDX, or text files opens them with existing save/discard/cancel protection.
3. Create Markdown files and folders, rename, duplicate, copy, cut/paste, move, reveal, and copy paths.
4. Delete requires confirmation and uses the system Trash/Recycle Bin. Collisions never overwrite files.
5. Operations remain inside the selected folder; symlinks cannot escape that boundary.
6. Moving/renaming open files updates every affected window's path while preserving unsaved text.
   Deleting an open document preserves its buffer as an unsaved document.
7. Directory changes refresh the tree; errors are visible, and large folders load on demand.
8. Keyboard navigation, resizing, focused tests, production build, and documentation are complete.

## Implementation and Verification

- Added native and titlebar Open Folder / Close Folder, a resizable lazy tree, and toolbar/context
  actions for create, rename, duplicate, copy/cut/paste, move, Trash, reveal, and path copy.
- Canonical root grants and link/traversal guards protect main-process operations; copy staging
  cleans up failures. Loaded-directory watchers and explicit Refresh keep entries current.
- Moves remap every affected editor window, including aliases; deleted files preserve their buffers
  as untitled documents. A save/mutation gate plus old-path acknowledgment protects save destinations.
- Added filesystem, IPC, accessibility, clipboard, and asynchronous-selection regressions, plus a
  hidden Electron smoke using isolated fixtures and simulated Trash. Screenshot layout inspected.
- Full verification with T_155: 84 test files / 796 tests passed, one existing Windows mode-bit skip;
  lint, TypeScript/production build, folder/code smoke, save smoke, renderer security smoke, and
  change-review smoke passed. PRODUCT, ARCHITECTURE and CHANGELOG updated.
