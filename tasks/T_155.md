# T_155: Code and Plain Text Reference Files

## Status

Done

## Summary

Extend the folder workflow for knowledge bases with a dedicated CodeMirror editor for code,
configuration, and plain text files. Keep Markdown's visual workflow and preserve file text.

## Acceptance Criteria

1. Code/configuration/plain text files open from the folder tree, native picker, recents,
   file drops, and OS handoff. Markdown retains rich-text/source/diff editing.
2. Line numbers, syntax highlighting, folding, undo, search/replace, and optional wrapping.
3. Loading and saving code bypass Markdown normalization and diagram processing. Text,
   indentation, BOM, and consistent LF/CRLF line endings remain intact.
4. Binary or unsupported-encoding files fail without replacing the active buffer.
5. Folder moves/deletion recovery and external-change review support code and text.
6. Regression tests, Electron smoke, build, and documentation pass.

## Implementation and Verification

- Dedicated CodeMirror editor for non-Markdown files, with lazy syntax support, a language override,
  line numbers/folding/history, wrapping and search/replace. Markdown keeps the existing viewer.
- Shared file-type catalog supports folder/native/recent/drop/OS entry points. Strict UTF-8 reads
  retain BOM and reject binary data/unsupported encoding; code/text loads are bounded to 8 MB.
- Raw code bypasses Markdown serialization and diagram conversion; exact dirty checks and text-file
  Save As preserve contents. Consistent LF/CRLF/CR and mixed endings are covered by tests.
- Text documents reuse saves, folder remapping/deletion recovery, and external-change review. The
  shared code review skips Markdown-specific image folding; switching back restores Markdown mode.
- Added decoding/catalog, CodeMirror preservation/history/highlighting/search/review, and exact-save
  regressions. Extended the Electron folder smoke with byte-identical BOM/CRLF saves, editing,
  protected document replacement, code review, binary rejection, and a clean Markdown round trip.
- 84 test files / 796 tests passed, one existing Windows mode-bit skip; lint and production build
  passed. Folder/code, document-save, renderer-security and change-review Electron smokes passed.
- PRODUCT, ARCHITECTURE and CHANGELOG updated; real code-editor screenshot visually inspected.
