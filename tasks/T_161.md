# T_161: YAML-backed document properties

Status: Complete

Add a small Markdown document-properties form for title, type, tags, status, owner, and review date. Store properties in YAML frontmatter (review_date for the review date; tags as a sequence). Offer Edit/Document Properties and a compact status-bar entry. Preserve unrelated metadata and document content, support custom type/status values, validate dates, and apply changes to the unsaved buffer with undo rather than writing directly to disk.

Keep the existing raw frontmatter editor. Reject malformed or incompatible YAML without overwriting it, and reject stale forms when the document changes. Support rich-text and source editing; disable properties for plain text/code and read-only comparisons. Validate transformations, dialog behavior, actual Electron editing/undo/save/reopen, build, lint, and visual layout. Update product, architecture, and changelog.

Implementation:
- Edit and status-bar actions open a compact six-field form with custom type/status suggestions, one tag per line, and a validated review_date.
- YAML transformations preserve document body, BOM/newline style, and unrelated properties/comments. Block mappings use original offsets; flow mappings retain structure through the YAML library. Changed blank fields remove their keys; untouched fields remain byte-identical.
- Source application is one CodeMirror change; rich-text application changes the Lexical frontmatter node with a history boundary. Changes remain unsaved until normal Save.
- Document identity and exact buffer snapshots prevent stale forms from overwriting changes. Invalid/incompatible metadata shows an error without applying a replacement.
- PRODUCT, ARCHITECTURE, CHANGELOG, and npm test:properties documented/updated.

Validation:
- All 30 focused tests pass (21 YAML transformation cases, 5 dialog cases, 4 existing titlebar tests).
- Real Electron smoke passes six-field editing, custom values, cancellation/date validation, body/metadata preservation, rich/source undo and redo, Apply without saving, normal Save/reopen, stale snapshots, untitled properties, invalid YAML typed in source, and code/text/diff restrictions.
- Wide and small-window dialog screenshots visually inspected; compact layout scrolls fields while keeping validation and footer actions accessible.
- Production build, lint, JavaScript syntax, and whitespace checks pass.
