# T_152: Shared Change Review

## Status

Done

## Summary

Use one change viewer for editor diffs, AI proposals, and MCP writes. Preserve the existing
approval and stale-proposal boundaries while improving navigation through document changes.

## Acceptance Criteria

1. All three review surfaces use the same side-by-side viewer with line and inline highlights.
2. Embedded image payloads start collapsed and can be expanded independently in either pane.
3. Previous/Next change controls navigate changed chunks, including insertions and deletions.
4. Hide unchanged sections retains context and lets users reveal hidden lines or show everything.
5. Identical documents show a clear no-changes state and disable change navigation.
6. Reviews remain read-only; copying and approval use the complete, unmodified proposal.
7. Source editing, switching modes, external diff updates, and approval callbacks still work.
8. Regression tests, lint, and build pass; product and architecture documentation are updated.

## Implementation

- Added `ChangeReview`, a shared read-only CodeMirror MergeView with line and inline highlights,
  labeled panes, change counts, wrapping Previous/Next navigation, and Hide unchanged sections.
  Unchanged blocks retain three context lines and can be revealed locally or all at once.
- Reused the existing image folding extension in both panes without altering comparison inputs.
- Replaced AI's plain-text previews and MCP's quadratic line-diff renderer with the shared viewer.
  Approval callbacks, stale-proposal checks, and Copy proposed continue using the complete inputs.
- Added a source/diff adapter using MDXEditor's public cells. The rich-text tree remains mounted;
  source edits retain undo history and external updates apply in place. Display-only changes do
  not publish document edits. App supplies the same theme to all review surfaces.
- Expanded review dialogs to accommodate side-by-side content with a bounded shared scrollbar.
- Added 13 regressions for navigation, boundary changes, identical documents, both types of folding,
  large image data, exact proposal copying, explicit approval, source undo, and external updates.
- Added a hidden Electron smoke for actual review layout, scrolling, MCP/AI/editor flows, and source
  keyboard editing after review. Updated PRODUCT, ARCHITECTURE, and CHANGELOG.
