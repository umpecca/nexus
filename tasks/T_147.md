# T_147: Harden AI Chat HTML and Renderer IPC

## Status

Done

## Summary

Replace regex-based chat sanitization with a maintained DOM parser and explicit allowlist, add a
renderer Content Security Policy, and restrict privileged IPC to registered main editor frames.

## Acceptance Criteria

1. Chat retains prose, code, lists, tables, and safe links. Scripts, embedded documents, forms,
   event handlers, dangerous URL schemes, and unexpected attributes cannot reach the chat DOM.
2. Encoded and unquoted JavaScript URLs are removed, including in streamed/incomplete Markdown.
3. The main renderer blocks inline script execution and preserves images, PDF preview, and the
   local JavaScript worker without permitting eval in the renderer.
4. Privileged IPC rejects unregistered windows, subframes, navigated frames, and malformed
   sensitive payloads. Confirmation responses are scoped to the requesting window.
5. Security regression tests, lint, syntax checks, TypeScript, and the production build pass.

## Implementation

- Added DOMPurify as a direct dependency and used a private sanitizer instance so Mermaid's global
  hooks/configuration cannot change the chat allowlist. Added jsdom only as a test dependency.
- Preserved prose, lists, code, tables, HTTP/HTTPS/mail links, and anchors; excluded active content,
  images, embeds, forms, arbitrary attributes, and file/data/blob/relative links in assistant HTML.
- Added main-renderer CSP with no inline-script or eval exception. Vite uses a random development
  script nonce for React refresh and permits HMR sockets. Local snippets are disposable worker
  source rather than runtime Function compilation, preserving async execution under the policy.
- Routed privileged app IPC through registered-main-frame and exact-document URL checks, added
  sensitive payload validation, blocked other main-window navigations, rejected embedded-editor
  subframes, and scoped MCP/SFTP decisions, selections, and stream aborts to their owning windows.
- Added a hidden Electron smoke test with isolated in-memory browser storage and synthetic data,
  and wired it into desktop CI after the renderer build. Included the DOMPurify license in packages
  and updated the product, architecture, settings/security documentation, and changelog.
