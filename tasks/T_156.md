# T_156: Document Image and Asset Panel

## Status

Done

## Summary

Inspect document images and their contribution to Markdown size. Explicitly embed, extract,
replace, and repair image references without switching away from the current editor view.

## Acceptance Criteria

1. Optional panel opens from View or the status bar in Markdown rich text, source, and diff views.
2. Markdown inline/reference images and HTML images show previews, dimensions, image byte sizes,
   source paths, missing-file states, and embedded-source contribution to document size.
3. Embed converts a linked image into data. Extract writes a new file and inserts a relative path.
   Replace chooses a new image; locate repairs a missing path. Cancellation does not edit content.
4. Actions preserve surrounding syntax, reject stale results, retain dirty/save semantics, and
   never silently overwrite existing assets. Source edits support undo.
5. Meaningful parsing/I/O/panel regressions and a real Electron workflow pass alongside build/lint.
6. PRODUCT, ARCHITECTURE, and CHANGELOG describe the behavior.

## Implementation and Verification

- Optional Images & Assets sidebar toggled from both View menus or the status bar, available
  across Markdown rich/source/diff views. Preview dimensions, actual image bytes, missing states,
  destination paths, and embedded-source share of current UTF-8 document size.
- AST inventory groups inline/reference/HTML images and maps shortened base64 payloads back to
  exact source spans. Ignores code/comments and src-like text in other HTML attributes. Destination
  edits preserve titles/alt text and source undo/redo; App rejects late results against live buffers.
- Trusted IPC bounds image reads/embedding to 40 MB, downloads remote images only for explicit
  embedding, and uses native file pickers. Extraction flushes temporary bytes and creates a new
  destination exclusively, with encoded relative references and no asset replacement/deletion.
- Encoded local paths resolve correctly for rich preview, diagram reads, and exports. Cached
  thumbnail refresh remounts the preview to restore dimensions without changing document content.
- Parsing/I/O/panel regressions cover multi-megabyte data, syntax preservation, duplicate definitions,
  missing paths, cancellation, collisions, path encoding, remote MIME checks, and cached dimensions.
- Real Electron workflow covers panel layout/previews, source undo/redo, embed/extract/replace/locate,
  stale picker results, unsaved/disk boundaries, and asset actions in all Markdown views.
- PRODUCT, ARCHITECTURE, and CHANGELOG updated. Real rich/source/diff screenshots inspected.
- 87 test files / 812 tests passed, with one existing Windows mode-bit skip. Lint and production
  build passed; asset, folder/code, and renderer-security Electron smokes passed. Syntax and
  whitespace checks passed. Existing Vite deprecation/chunk-size warnings remain unchanged.
