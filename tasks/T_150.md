# T_150: Collapse Inline Image Data in Source and Diff Views

## Status

Done

## Summary

Collapse embedded base64 image payloads by default in the source view and both diff panes,
with a per-image control to expand the exact source and collapse it again.

## Acceptance Criteria

1. Embedded Markdown and HTML images start collapsed, retaining surrounding syntax and the data URL prefix.
2. Each payload can be expanded and collapsed, including in read-only diff panes.
3. Folding changes only the display, preserving the complete source for saving, copying, editing, and comparison.
4. New images are collapsed, expanded images remain expanded while editing, and search can reveal hidden source.
5. Code examples, ordinary links, and external image URLs are unaffected.
6. Automated behavior tests, lint, and build pass.

## Implementation

- Added a CodeMirror state field to the shared source/diff extensions. Each image retains its
  syntax, alt text, and data URL prefix while an accessible button replaces only its payload.
- Detects Markdown images, used image reference definitions, HTML image sources, and MDXEditor's
  escaped `data\:image` syntax. Code examples, links, and external image URLs remain visible.
- Expanded ranges follow edits; newly inserted images default to collapsed. Search selections and
  caret placement inside hidden data expand it. Select-all can copy the complete source while folded.
- Uses short payload stand-ins during detection, retaining original source offsets to avoid parsing
  large base64 payloads character by character. Folding never edits the document or diff inputs.
