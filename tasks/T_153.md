# T_153: Folded Image Previews and Bulk Folding

## Status

Done

## Summary

Inspect embedded images from source and review views without revealing their base64 payloads.
Provide bulk image-data folding controls in source mode and the shared change viewer.

## Acceptance Criteria

1. Hovering or keyboard-focusing a folded image offers a bounded thumbnail preview.
2. A Preview control opens the thumbnail on click without expanding the payload; it can be dismissed.
3. Preview works for Markdown, HTML, referenced images, and escaped data URLs already detected by folding.
4. Invalid image data shows an unavailable state and leaves folding controls usable.
5. Expand all / Collapse all affect all embedded image payloads in the source document or both review panes.
6. Preview and bulk folding never alter Markdown, undo history, copy/save contents, or approval inputs.
7. New images still start collapsed; previews clean up on edits, scrolling, document replacement, and close.
8. Regression tests, lint, build, Electron checks, and documentation updates pass.

## Implementation

- Added a separate Preview control to every image-fold widget. Hover or keyboard focus lazily
  loads a bounded thumbnail; clicking Preview pins it. Dimensions appear on load, and corrupt
  or unsupported image data shows Preview unavailable without affecting the folding controls.
- Native popovers stay inside the widget's DOM while escaping editor and dialog clipping. Close,
  outside click, Escape, scroll, resize, edits, and widget destruction clean up previews. Escape
  is handled before dialog handlers so dismissing a thumbnail cannot reject an AI/MCP proposal.
- Preview reads the current complete data URL only when requested, including escaped destinations,
  HTML image sources, SVG payloads, and referenced image definitions detected by existing folding.
- Added display-only bulk effects and Expand all / Collapse all controls for source and both review
  panes. Controls cover images in hidden unchanged sections; newly inserted images remain collapsed.
- Added 13 regressions covering thumbnail lifecycle, unavailable data, exact document preservation,
  bulk folding in read-only and source views, hidden images, and Escape ownership in review dialogs.
- Extended the hidden Electron review smoke with real SVG loading, native hover/click previews,
  viewport bounds, dismissal, and bulk controls across source, editor diffs, AI, and MCP.
- Updated PRODUCT, ARCHITECTURE, and CHANGELOG.
